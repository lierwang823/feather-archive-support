PARROT CRIME FILES

使用支持

鹦鹉犯罪档案是本地优先的 iPhone App。你的案卷、鹦鹉资料和照片默认仅保存在设备上；只有读取商品信息、购买和恢复购买需要连接 Apple App Store。

常见问题

如何新建一份案卷？

从首页点击“拍下犯罪现场”；首次使用的空白首页也会显示“建立第一份案卷”。你可为“案发现场”和“嫌疑鸟特写”分别从相册多选照片或直接拍照；只有一张照片也可以保存案卷。填写案卷信息后保存即可。

可以修改已保存的案卷吗？

可以。打开任一案卷，在右上角点击编辑图标，可修改文字、照片和照片构图。

如何建立鹦鹉档案？

进入“鹦鹉档案”，点击右上角“+”。可记录名称、品种、纪念日、备注和身份照片；之后新建案卷时可关联该档案。

如何生成并分享通缉令？

打开案卷详情即可免费预览 3:4 海报。点击“生成通缉令并分享”后，App 会把海报交给 iOS 系统分享面板；你决定发送到哪个 App 或保存到哪里。

免费发布与永久解锁

  • 建档、编辑、案卷本地保存、海报预览和 JSON 备份恢复始终免费。
  • 未永久解锁时，每个自然周可免费成功发布 2 次通缉令，周一按本地时间刷新；取消或失败不扣次数。
  • 一次性 Non-Consumable（非消耗型）购买可永久解锁无限保存到相册和系统分享，不是订阅。
  • 购买与恢复购买由 Apple App Store 处理，需要网络；实际价格以 App Store 显示的本地化价格为准。

备份与恢复

导出备份

  1. 进入“设置与数据”。
  2. 在“备份与恢复”中点击“导出单文件备份”。
  3. 在系统文件选择器中选择保存位置。

备份是一个 JSON 文件，包含案卷、鹦鹉资料、照片、头像和格式版本。请妥善保管，不要随意发送给他人。

从备份恢复

  1. 进入“设置与数据”，点击“从文件恢复”。
  2. 在系统文件选择器中选取此前导出的 JSON 备份。
  3. 本 App 会先校验文件，并显示案卷、鹦鹉资料、新增记录和同 UUID 冲突数量。
  4. 确认后，选择“跳过同 UUID 记录”或“用备份覆盖同 UUID 记录”，再执行恢复。

请勿手动修改备份内容；无法读取、格式不匹配、版本不支持或记录重复的文件不会被导入。

相机和照片权限

本 App 只在你主动点击“直接拍照”或“从相册取证/选择”时请求权限。若之前拒绝了权限，可在 iPhone 的“设置”中恢复：

  • 照片：设置 → 隐私与安全性 → 照片 → 鹦鹉犯罪档案
  • 相机：设置 → 隐私与安全性 → 相机 → 鹦鹉犯罪档案

更改后回到本 App，再次点击相应操作即可。模拟器或没有相机的设备请使用相册选图。

本地数据删除

你可以单独删除案卷或鹦鹉档案；也可以在“设置与数据”中删除全部本地数据。删除不可撤销，建议先完成并确认备份。卸载本 App 也会移除其本地数据库。
